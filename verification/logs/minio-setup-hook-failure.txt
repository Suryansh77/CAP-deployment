===== SECOND FAILURE / ROOT CAUSE =====
The first remediation set HOME=/tmp and preserved the non-root securityContext.
The subsequent hook failed differently because `mc ready` was invoked with the raw
MinIO URL instead of a configured mc alias.

Observed error:
mc: <ERROR> Couldn't construct anonymous client for `http://cap-minio:9000`.

Diagnosis:
`mc ready` expects a configured target/alias. The hook therefore must configure
the alias first and then invoke `mc ready capminio`.

Remediation:
1. Configure the capminio alias with the existing MinIO credentials.
2. Poll `mc ready capminio`.
3. Create the bucket after readiness.

Security posture was not relaxed.
